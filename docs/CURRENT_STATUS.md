## 完成测量后如何决策

1. 正常检索差、完整支持材料较好：针对检索或材料选择做一项改动。
2. 完整支持材料仍差：进一步区分阅读漏抽、答案综合、拒答和评分契约；不直接认定检索或模型能力是唯一原因。
3. 正常流程接近饱和：另立更合适难度的面板，不能事后挑这批题来制造提升。
4. 正常流程有成功和可修复失败：再比较总分反馈与失败轨迹反馈；随后独立检验经验复用和模块选择。

MuSiQue 用于受控多跳机制开发，BrowseComp 保留困难检索与迁移确认，两者成绩不能互相替代。全文窗口邻域读取、候选条件表、稠密检索和更强修改器都是候选改动，按损失位置选一项验证，不同时启用。
